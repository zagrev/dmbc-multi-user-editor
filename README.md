# dmbc-multi-user-editor

A replacement editor for WordPress that supports multiple simultaneous users.

The current release is a scaffold only; collaborative editing is not implemented.

## Setup

Run `composer install` in this directory, then activate **dmbc-multi-user-editor**
in WordPress. Requires WordPress 6.0+ and PHP 8.0+.

## Updates and releases

Git origin: `git@github.com:zagrev/dmbc-multi-user-editor.git`.

Updates use Composer-managed Plugin Update Checker and the
[GitHub repository](https://github.com/zagrev/dmbc-multi-user-editor).
Publish a versioned GitHub release with a `dmbc-multi-user-editor.zip` asset
containing the plugin folder and production `vendor/` dependencies.
Source-only archives are not accepted as updates.

See [readme.txt](readme.txt) for installation, release packaging, and development
instructions.
